Place the images you want shown in the admin dashboard into the `public/uploads/store/` folder with the filenames below.

Expected filenames (examples):
- store-front-1.jpg
- store-front-2.jpg
- shirt-1.jpg
- shirt-2.jpg
- shirt-3.jpg
- shirt-4.jpg

After copying images into that folder, reload the admin dashboard at /admin to see them.

If you want different filenames, update `app/admin/page.tsx` gallery array accordingly.
